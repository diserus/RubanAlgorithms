# Полубыстрое преобразование Фурье (ППФ)

Реализация по методичке А.А. Рубан, Т.Э. Разинкиной
«Теория сложности вычислительных процессов и структур»
(формулы 2.3a и 2.3b).

---

## 1. Задача

Прямое дискретное преобразование Фурье (ДПФ) для массива `x[0..N-1]`:

```
X[k] = (1/N) · Σ_{n=0}^{N-1} x[n] · e^(-2πi·k·n/N),   k = 0..N-1
```

**Проблема:** для каждого из `N` выходов суммируется `N` слагаемых, то есть всего
`N²` умножений. Для больших `N` это очень много (при `N = 10⁶` — порядка `10¹²`
операций).

Идея ППФ — считать то же самое, но быстрее.

---

## 2. Основная идея

Пусть `N = p1 · p2`. Разложим индексы входного и выходного сигналов на две части:

```
n = j2 + p2 · j1        j1 = 0..p1-1  (строка)
                        j2 = 0..p2-1  (столбец)

k = k1 + p1 · k2        k1 = 0..p1-1
                        k2 = 0..p2-1
```

Тогда вместо одной большой суммы из `N` слагаемых **считаем две маленькие**:

### Шаг 1 — ДПФ по столбцам (размер `p1`)

```
A1[k1][j2] = (1/p1) · Σ_{j1=0}^{p1-1} x[j2 + p2·j1] · e^(-2πi·j1·k1/p1)     (2.3a)
```

### Шаг 2 — ДПФ по строкам (размер `p2`) с поправкой на фазу

```
X[k1 + p1·k2] = (1/p2) · Σ_{j2=0}^{p2-1} A1[k1][j2] · e^(-2πi·j2·(k1 + p1·k2)/N)   (2.3b)
```

Обратите внимание: второй проход идёт по строкам `k1`, и множитель зависит
одновременно от `j2` и от номера строки `k1`.

---

## 3. Наглядный пример: `N = 8`, `p1 = 2`, `p2 = 4`

Раскладываем вход в таблицу `2 × 4` (нумерация — по строкам):

```
строка j1=0:   x0  x1  x2  x3      ← n = 0..3
строка j1=1:   x4  x5  x6  x7      ← n = 4..7
               j2=0  1   2   3
```

**Шаг 1** (`p1 = 2`, каждый столбец — сумма и разность):

```
A1[0][j2] = (x[j2] + x[4+j2]) / 2
A1[1][j2] = (x[j2] - x[4+j2]) / 2
```

**Шаг 2** (`p2 = 4`, для каждой строки `k1` — ДПФ длины 4):

```
X[k1 + 2·k2] = (1/4) · Σ_{j2=0}^{3} A1[k1][j2] · e^(-2πi·j2·(k1 + 2·k2)/8)
```

Выход `X[k1 + 2·k2]` получается уже в правильном порядке `k = 0..7`.

---

## 4. Почему это работает

Хитрость — в показателе экспоненты. Раскроем произведение индексов:

```
n·k = (j2 + p2·j1)·(k1 + p1·k2)
    = j2·k1 + p2·j1·k1 + p1·j2·k2 + p1·p2·j1·k2
```

Поделим на `N = p1·p2`:

```
n·k / N = j1·k1/p1 + j2·(k1 + p1·k2)/N + j1·k2
```

Последнее слагаемое `j1·k2` — **целое число**, а `e^(-2πi·целое) = 1`, поэтому оно
просто исчезает. Остаётся:

```
e^(-2πi·j1·k1/p1) · e^(-2πi·j2·(k1 + p1·k2)/N)
```

Первая экспонента зависит только от «строки» `j1`, вторая — только от «столбца»
`j2`. Именно поэтому большую сумму удаётся разбить на два вложенных прохода:
сначала по столбцам, потом по строкам.

---

## 5. Трудоёмкость

Умножения:

| Шаг | Формула | Количество |
|-----|---------|-----------|
| 1   | `p2` столбцов × `p1` выходов × `p1` слагаемых | `p1²·p2` |
| 2   | `p1` строк × `p2` выходов × `p2` слагаемых    | `p1·p2²` |

Итого:

```
T(N) = p1²·p2 + p1·p2² = N·(p1 + p2)
```

Если выбрать `p1 ≈ p2 ≈ √N`, то

```
T(N) = N·(√N + √N) = 2·N^(3/2) = O(N^(3/2))
```

**Важный нюанс:** `N^(3/2)` получается только при **сбалансированном**
разложении `p1 ≈ p2`. Если разложение неудачное (например, `p1 = 1`, `p2 = N`),
то `T = N·(1 + N) ≈ N²` и выигрыша нет. Поэтому `p1` и `p2` надо брать как можно
ближе друг к другу.

Сравнение методов:

```
обычное ДПФ:  O(N²)
ППФ:          O(N^(3/2))
БПФ:          O(N·log N)
```

ППФ — промежуточный вариант: быстрее ДПФ, но медленнее полного БПФ.

---

## 6. Обратное преобразование

Обратное ППФ вычисляется **по тем же формулам**, но:

1. в экспоненте знак меняется на противоположный (`-` → `+`);
2. убираются множители `1/p1` и `1/p2`.

---

## 7. Код

Файл `semi_fast_furie.py`:

- `ppf(x, p1, p2)` — прямое ППФ;
- `ppf_inv(X, p1, p2)` — обратное ППФ.

Прямое преобразование делит результат на `N`, обратное — не делит (как в `furie.py`).

Запуск:

```bash
python3 semi_fast_furie.py
```

Пример вывода:

```
x[n] = [1.0, 3.0, -2.0, 5.0, 0.0, -1.0, 4.0, -3.0]

Полубыстрое ПФ (N = 2*4 = 8):
 X = ['0.8750+0.0000j', '-0.2286-0.3107j', ...]
 T = C*N*(p1+p2) = 5*8*(2+4) = 240

Обратное ППФ: ошибка = 3.77e-15
```

---

## 8. Связь с БПФ

ППФ — это один «шаг» большого деления. Если продолжать делить `p1` и `p2` дальше
(например, всё время пополам, пока не останутся блоки по 2), получится уже
**быстрое преобразование Фурье**. То есть БПФ — это ППФ, применённое рекурсивно.
